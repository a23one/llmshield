Every prompt follows the same route.

Three of the four stops are inside your own process. Only the redacted copy travels, and the reply is restored before your code sees it.

Routing slipOne request
StepStopWhere
1Find the personal detailsPatterns, Luhn checks and English dictionariesYour process
2Swap each for a placeholderSarah Johnson becomes <PERSON_0>Your process
3Send the copy with your usual clientChat, streaming, tools or structured outputProvider
4Write the originals back into the replyEven when a stream splits a placeholderYour process

The reply comes back redacted too

The model writes with placeholders, because placeholders are all it has seen. LLMShield fills them back in as the stream arrives.

Same person, same placeholder, every page.

Entity maps are cached for the whole conversation, so the model can follow who's who across turns without ever learning a name.

It works past plain text.

Tool calls and structured output are restored too, so your functions and your types get real values, not placeholders.

Tool calls

The model decides to call your function using the only number it knows. Your function receives the real one.

The model asks for
make_call(
    phone="<PHONE_4>",
    note="Refund for <PERSON_0>",
)
Your function gets
make_call(
    phone="+44 20 7946 0958",
    note="Refund for Sarah Johnson",
)

Structured output

Ask for a Pydantic model and the parsed fields come back with the originals already in place.

The model returns
Contact(
    name="<PERSON_0>",
    email="<EMAIL_2>",
)
Your code gets
Contact(
    name="Sarah Johnson",
    email="sarah.j@acmecorp.com",
)

Streaming

          
You get plain text chunks with the originals already back in.


stream = shield.ask(
    model="gpt-5",
    messages=messages,
    stream=True,
)
for chunk in stream:
    print(chunk, end="", flush=True)

        

        

          
Without a client

          
Cloak and restore by hand for any model or framework.


shield = LLMShield()

cloaked, entity_map = shield.cloak(
    "Call John Doe on +44 20 7946 0958"
)
# "Call <PERSON_0> on <PHONE_1>"

reply = your_model(cloaked)
restored = shield.uncloak(reply, entity_map)

Adjust what counts as secret

        
Your own company name shouldn't become a placeholder, and some teams want links left readable. Every setting is a constructor argument.

shield = LLMShield(

          
    llm_func=client.messages.create,

Questions worth asking.

        

          

            Does redaction make the model's answers worse?
            

              
For most tasks, no. Placeholders are typed, so the model still knows it's looking at a person, an email or a phone number, and the same person keeps the same placeholder throughout.

              
Tasks that depend on the value itself, like checking whether an email address is spelled correctly, can't work on a placeholder. Allowlist those terms or switch that type off.

            

          

          

            What can it miss?
            

              
Detection uses patterns, checksums and English dictionaries. It can miss unusual names, text in other languages, and identifiers without a recognisable format, such as postcodes or internal account numbers.

              
Treat it as one layer of protection, and check its output against samples of your own data before you rely on it.

            

          

          

            Where is the entity map kept?
            

              
In an in-memory LRU cache inside your Python process, holding up to 10,000 conversations by default. LLMShield doesn't write it to disk or send it anywhere. If you choose to persist maps yourself, store them as carefully as the original data.

            

          

          

            Which providers and frameworks does it support?
            

              
OpenAI, Anthropic, Google Gemini, Cohere and xAI are tested directly, along with any API that follows the OpenAI format. For anything else, call cloak() before your request and uncloak() on the response.

            

          

          

            My prompts already contain < and >. Will that break?
            

              
Choose different delimiters with start_delimiter and end_delimiter, for example [[PERSON_0]].

            

          

          

            What does the AGPL licence mean for my product?
            

              
LLMShield is licensed under AGPL-3.0, which can require you to share source code when you offer software built on it over a network. Read the licence and check it with your legal team before shipping it in a closed-source product.
